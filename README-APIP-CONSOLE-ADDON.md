# APIP Private Console Add-on

This add-on adds a local-first private console to APIP. Read `docs/APIP_PRIVATE_CONSOLE_V1.md` for setup, API configuration, privacy, and limits.

**Default is no API spending.** Start with `run-apip-console.cmd`; it works in demo mode. The server binds to `127.0.0.1` only.
