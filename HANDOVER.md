# Reusable AI Builder Handover

## Mission
Build a reusable, evidence-driven system that helps the owner test whether AI-assisted work can generate real personal income, initially with zero operating cost.

## Operating principle
AI proposes and builds. Automated tests verify. The owner controls consequential decisions. Evidence determines what can be claimed.

## Current project
AI Personal Income Protocol (APIP).

## Repository
https://github.com/Stakeandwager/ai-personal-income-protocol

## Owner's cost constraint
No paid APIs, subscriptions, advertising, or other operating expenses until the project has verified earnings and the owner explicitly approves a spending limit.

## Required evidence
Distinguish ideas, offers, interest, orders, payments, costs, refunds, and payouts. Never report projected revenue as received income. Record proof references where safe.

## Safety
Never store passwords, API keys, bank account numbers, PINs, OTPs, or private financial credentials in this repository. Never initiate payments, purchases, financial transfers, or external commitments without explicit authorization.

## Reusable architecture
Keep project identity, decisions, verified state, tasks, tests, and income evidence in separate files. Use templates so another project can adopt the same system without inheriting unrelated project assumptions.

## Handover rule
Before ending a work session, update PROJECT_STATE.md and TASKS.md with verified progress, outstanding issues, and the next concrete action. Record owner-approved changes in DECISIONS.md.
